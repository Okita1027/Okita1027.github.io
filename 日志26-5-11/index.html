网络共享盘问题

问题描述： xxx无法访问，你可能没有权限使用网络资源。请与这台服务器的管理员联系以查看你是否有访问权限。
用户账户限制阻止了此用户进行登录，例如不允许使用空密码，登录次数的限制，或强制实施某个策略。此用户无法登陆，因为该账户当前已被锁定。……

解决办法：

  1. 给账户设置密码

Windows 默认的安全策略会阻止没有密码（空密码）的账户通过网络进行访问。
操作：直接给当前登录的 Windows 账户设置一个开机密码。
使用：设置好密码后，在另一台电脑上访问共享时，输入这台主机的用户名和新设置的密码即可顺利访问。这是最稳妥、最推荐的解决方式。

  1. 修改组策略（允许空密码登录）

如果觉得设置密码太麻烦，或者必须使用空密码，可以通过修改组策略来解除限制：

在主机上按下键盘上的 Win + R 键，输入 gpedit.msc 并回车，打开“本地组策略编辑器”。
在左侧依次展开：计算机配置 -> Windows 设置 -> 安全设置 -> 本地策略 -> 安全选项。
在右侧的策略列表中，找到 “账户: 使用空密码的本地账户只允许进行控制台登录”。
双击它，将其设置为 “已禁用”，然后点击确定。
按下 Win + R，输入 cmd 打开命令提示符，输入 gpupdate /force 强制刷新策略使其生效。

  1. 检查账户是否被锁定或禁用

如果设置了密码依然报错，可能是账户本身的状态出现了异常（例如尝试次数过多被锁定）：

在主机上按下 Win + R，输入 lusrmgr.msc 打开“本地用户和组”（注：Windows 家庭版可能没有此功能）。 点击左侧的 “用户”，在右侧找到你正在使用的账户。 右键点击该账户选择“属性”，确保 “账户已禁用” 没有被勾选。 如果账户被锁定，可以通过命令提示符（管理员身份运行）输入 net user 你的用户名 /unlock 来解锁。

  1. 检查“拒绝从网络访问”策略

有时候账户被系统策略明确拒绝了网络访问权限：

在 gpedit.msc 组策略编辑器中，依次展开：计算机配置 -> Windows 设置 -> 安全设置 -> 本地策略 -> 用户权限分配。
在右侧找到 “拒绝从网络访问这台计算机”。
双击打开，查看里面是否有你的用户名或 Guest 账户。如果有，请将其删除，然后保存退出。
